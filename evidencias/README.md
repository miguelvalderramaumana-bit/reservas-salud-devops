# Registro de evidencias reales

Capturar sin tokens ni información privada:

1. Repositorio público: URL, archivos y visibilidad.
2. Historial de commits y rama de trabajo.
3. Pull request: diff, descripción, resultado y fusión.
4. Terminal: build, up y compose ps.
5. Docker Desktop: contenedor y estado.
6. Navegador en localhost:8080 y resultado de simulación.
7. Logs tras visitar la página y una ruta inexistente.
8. Stats con fecha y explicación de CPU y memoria.
9. Stop y compose ps -a con estado detenido.

Cada figura del informe debe identificar lo observado, el comando o vista de origen y su relación con el requisito. No confundir resultados esperados con resultados medidos.
